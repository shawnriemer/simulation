# simulation

## Overview
My vision is to create a site where you can simulate, visualize, and learn from all sorts of different scenarios. The inspiration came from my interest in the Martindale betting strategy as a kid and can be easily extended to other gambling-related scenarios as well (ideally in a way to deter gambling). But why stop there? Anything can be modeled to a degree, so the real interest could be covering random topics such as seed combinations in March Madness, evolution (shout out to Primer), or politics.
